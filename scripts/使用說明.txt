移動整理 0.1.0 試用版
================================

把檔案或資料夾搬到別的資料夾時，自動處理重名，還可以順手建一個今天日期的資料夾。
適用 Windows 10／11（64 位元）。不用另外安裝任何東西，MoveTidy.exe 一個檔案就能用。


【開始使用】

1. 先把這個資料夾從壓縮檔裡「解壓縮出來」，放到一個固定的位置，例如「文件」裡。
   之後別再搬動它（右鍵選單會記住程式在哪裡）。

2. 點兩下 MoveTidy.exe，打開設定視窗。
   如果跳出藍色的「Windows 已保護您的電腦」：點「其他資訊」→「仍要執行」。
   （這個程式沒有付費購買數位簽章，所以 Windows 會先提醒一次。）

3. 左邊點「右鍵選單」→「安裝右鍵選單」。

4. （可選）左邊點「常用目的地」→「新增…」，選一個常放東西的資料夾，
   右鍵選單就會多出「移到〔這個資料夾〕」，點一下直接搬過去。

5. 打開檔案總管，對任何檔案或資料夾，或資料夾的空白處按右鍵：
   Windows 11 要先點「顯示更多選項」，或按住 Shift 再按右鍵，
   就會看到「移動整理」。


【從舊版更新】

1. 關掉設定視窗，用新的 MoveTidy.exe 覆蓋舊的（放在原來的位置）。設定會保留。
2. 點兩下 MoveTidy.exe →「右鍵選單」→「重新安裝」。
   新版的右鍵選單有改，這一步做了才會換成新的
   （沒做就點舊選單的話，程式不會搬東西，會問你要不要更新）。


【右鍵選單裡有什麼】

- 移到「常用目的地」：直接搬，右下角小窗顯示進度，完成後自動關閉
- 移到「常用目的地\今天日期」：先建 11-21 這樣的日期資料夾再放進去（同一天搬好幾批都放進同一個）
  日期格式可在設定 →「命名規則」→「日期資料夾名稱」改成 1121、11月21日 或 2026-11-21
- 在資料夾「空白處」按右鍵 → 把這裡的項目移到今天日期資料夾：
  這一層的東西全部收進今天的日期資料夾（日期資料夾本身不動），數量不限
- 自動改名：選一個或多個檔案，留在原處只換名字，例如 20261124-153012-k7f2.jpg，
  之後自己手動搬到哪裡都不會重名。樣式在設定 →「自動改名」裡換
- 在資料夾「空白處」按右鍵 → 貼到這裡（重名自動改名）：
  先選檔案按 Ctrl+X（剪下）或 Ctrl+C（複製），到要放的資料夾再用它貼上，
  重名的自動加 (2)、(3)。系統原本的貼上照舊
- 撤回：搬完或改名完，右下角小窗上按「撤回」（滑鼠移上去小窗就不會自動關），
  或之後在右鍵選單點「撤回上一次」；檔案放回原處、名字改回原名
  搬過去之後被換掉或編輯過的檔案，撤回時不會動它，會告訴你是哪幾個；
  因為檔案正在使用而沒撤回的，關掉那個程式後可以再撤回一次
- 正在搬的時候小窗不能關；萬一電腦當掉或程式被結束，再打開一次程式就會自動收拾好
- 移到其他位置…：當場選目的地和命名方式，搬之前先看每個項目會變成什麼名字
- 設定…：打開設定視窗

命名方式有兩種：
- 保留原名：重名時自動加 (2)、(3)
- 純數字編號：001.jpg、002.png…，目的地已有號碼就接著編

可以一次選很多個檔案再按右鍵（Windows 限制最多 100 個；更多的話用上面的「空白處」整理）。設定視窗裡可以切換繁體／簡體。


【不想用了怎麼移除】

1. 打開 MoveTidy.exe →「右鍵選單」→「移除右鍵選單」
2. 刪掉這個資料夾
3. （可選）刪掉設定：在檔案總管網址列輸入 %APPDATA%\MoveTidy 後刪除

简体版说明
--------------------------------

1. 先把这个文件夹从压缩包里「解压出来」，放到固定位置（例如「文档」），之后不要再挪动。
2. 双击 MoveTidy.exe 打开设置窗口。
   如果出现蓝色的「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
3. 左边点「右键菜单」→「安装右键菜单」。
4. （可选）左边点「常用目的地」→「新增…」，选一个常放东西的文件夹。
5. 在文件资源管理器里对文件、文件夹或文件夹空白处按右键（Windows 11 先点「显示更多选项」，或按住 Shift 再按右键），
   就能看到「移動整理」。

从旧版更新：关掉设置窗口，用新的 MoveTidy.exe 覆盖旧的，再打开它 →「右键菜单」→「重新安装」，新的菜单项目才会出现。

右键菜单选 移到「常用目的地\今天日期」，会先建 11-21 这样的日期文件夹再放进去；
格式可在设置 →「命名规则」→「日期文件夹名称」改成 1121、11月21日 或 2026-11-21。
在文件夹「空白处」按右键 → 把这里的项目移到今天日期文件夹：这一层的东西全部收进今天的日期文件夹，数量不限。
自动改名：选一个或多个文件，留在原处只换名字（例如 20261124-153012-k7f2.jpg），样式在设置 →「自动改名」里换。
在文件夹「空白处」按右键 → 粘贴到这里（重名自动改名）：先按 Ctrl+X 或 Ctrl+C，再到目标文件夹粘贴，重名的自动加 (2)、(3)。
选中项目再右键时，Windows 最多只允许 100 个。
搬错或改错了：右下角小窗点「撤回」，或在右键菜单点「撤回上一次」，文件放回原处、名字改回原名。
移动之后被换掉或编辑过的文件，撤回时不会动它。正在移动时小窗不能关；万一程序被强制结束，再打开一次就会自动收拾好。
设置窗口里可以把界面切换成简体。
不用了：设置里「移除右键菜单」，再删掉这个文件夹即可。
